# Noodle Theory

A restaurant landing page built for the Ramen Shop Website mission.

## Live Site

[https://ramen-shop-landing-page.vercel.app](https://ramen-shop-landing-page.vercel.app)

## Overview

Noodle Theory is a fictional Seattle ramen bar website designed to feel like a real customer-facing restaurant page. The site focuses on a warm visual style, mobile responsiveness, clear restaurant information, and a more interactive menu browsing experience.

## Features

- Hero section with restaurant branding and CTA
- Menu highlights with photos, pricing, and clickable dish details
- Location and contact section
- Hours and directions
- Mobile-responsive layout
- Live deployment on Vercel

## Tech Stack

- Next.js
- React
- Tailwind CSS
- TypeScript

## Getting Started

Install dependencies:

```bash
pnpm install
```

Run the development server:

```bash
pnpm dev
```

Build for production:

```bash
pnpm build
```

## Mission Notes

This project was created to satisfy the mission requirements:

- Build a professional restaurant landing page
- Include menu, location, contact CTA, and hours
- Push code through GitHub workflow
- Deploy the final site with a live URL
